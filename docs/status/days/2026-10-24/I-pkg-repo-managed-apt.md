change: I.pkg.repo_managed on Ubuntu (rc.19 lite rig, real cook failed with an empty `add-apt-repository: exit status 1: `): Ubuntu 24.04's add-apt-repository refuses a one-line flat repository ("Unable to handle repository shortcut 'deb [trusted=yes] file:... ./'") and prints that on stdout, which snack's AddRepo never reads. On apt, `pkg.repo_managed` now writes /etc/apt/sources.list.d/<name>.list (one-line entries, [options] such as trusted=yes, signed-by, arch) or <name>.sources (deb822) itself and runs apt-get update, reverting the file if the update fails; `absent` deletes the file. Idempotency comes from that file's content, so a second cook reports no change and a changed url rewrites it. dnf/yum/zypper keep snack's path. Errors from shelled-out commands in the pkg, cron, group, user, selfupdate and winexec ingredients now quote both stderr and stdout (`ingredients.CommandError`).
