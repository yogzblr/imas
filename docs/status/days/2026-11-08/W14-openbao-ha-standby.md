The bootstrap script waits for an active node, takes "path is already in use" as success, checks the KV mount is version 2, and tells absent, upgrading, check-and-set refused and other errors apart in the Valkey password step, retrying up to 120 s and naming the error. The Job keeps a failed run (no ttlSecondsAfterFinished, Argo CD HookSucceeded), and `install.sh` prints every container of every pod of a failed hook Job (`kubectl logs job/` had shown one pod). The repaired script ran on the kept cluster, on a fresh KV mount too, and waited the upgrade answer out. Re-dispatch the HA run on a release with this fix.
